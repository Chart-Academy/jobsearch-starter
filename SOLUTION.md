# Finished Job Search Hub (reference)

This branch is a working version of what the day 1 and day 2 prompts build. Use it to see how a finished hub
looks, or to catch up if your build gets stuck:
```
git fetch origin solution
git checkout origin/solution -- hub.py site agents
```
That copies the finished hub, pages, and agents into your project. Your data/ files and notes stay as they are.
